# Super Mario Web 🍄

一款基于 HTML5 Canvas 的网页版马里奥风格平台跳跃小游戏，支持电脑与手机浏览器，横屏全屏体验更佳。

## 🎮 在线试玩

部署后可通过 GitHub Pages 访问。

## 🕹️ 操作说明

- **电脑**：方向键 / WASD 移动，空格 / ↑ / W 跳跃，R 重新开始
- **手机**：触屏虚拟按键（◀▶ 移动，跳 跳跃），横屏 + 全屏体验最佳

## ✨ 特性

- 像素风渲染 + 粒子特效
- Goomba 敌人巡逻与踩踏得分
- 问号方块出金币、砖块破坏
- 计分、金币、时间、生命 HUD
- 到达旗杆通关
- 响应式画布、全屏、横屏提示

## 📁 文件

- `index.html` — 单文件游戏，无外部依赖，双击即可本地运行
